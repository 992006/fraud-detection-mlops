# MLOps Credit Card Fraud Detection

A production-style machine learning pipeline for detecting fraudulent transactions.

## Pipeline Stages
1. Data Ingestion & Validation
2. EDA & Feature Engineering
3. Model Training & Experiment Tracking (MLflow)
4. API Deployment (FastAPI)
5. Containerization (Docker)
6. CI/CD (GitHub Actions)
7. Monitoring (Evidently)
